# Instruções deste projeto

Enquanto `RELATORIO_HTML_PROTEGIDO.md` existir, não execute scripts deste
projeto, testes que os importem ou o painel HTML em navegador automatizado.
Esses scripts já causaram rollback de correções. Para conferir alterações,
use inspeção de arquivos e validações estáticas que não executem o código.

O painel aberto pela usuária é `output/relatorio_telegram.html`. Consulte
`RELATORIO_HTML_PROTEGIDO.md` antes de editar ou regenerar seus arquivos.
